# cool-thing

Этот репозиторий содержит ретро-блог в стиле Neocities, готовый для публикации на GitHub Pages.

## Что сделано
- Добавлен файл `index.html` с относительными путями к изображениям и ресурсам.
- Убран абсолютный слэш (`/`) из всех локальных ссылок, чтобы сайт работал корректно на GitHub Pages.

## Как запустить локально
1. Откройте `index.html` в браузере.
2. Убедитесь, что файлы `TVS1.jpg`, `TVS2.jpg` и `noviy.jpg` находятся в той же папке, что и `index.html`.

## Как опубликовать на GitHub Pages
1. Создайте репозиторий на GitHub и залейте в него этот проект.
2. В настройках репозитория (`Settings > Pages`) выберите ветку `main` или `master` и директорию `/ (root)`.
3. Сохраните настройки. GitHub Pages начнет публикацию сайта по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Важно
- Если ваш сайт будет в корне пользователя (например, `https://<ваш-логин>.github.io/`), всё готово.
- Если сайт будет в папке проекта, путь к изображениям должен оставаться относительным, как в `index.html`.
